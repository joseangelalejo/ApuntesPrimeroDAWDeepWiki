# Actividad: Agenda de Contactos

## Premisa

Crea un programa en Java que administre una agenda de contactos usando métodos estáticos y arrays.

## Requisitos

### Añadir un contacto

- Se guardan el nombre y el teléfono en dos arrays paralelos.
- No se permiten más de 10 contactos.

### Buscar un contacto por nombre

- Se introduce el nombre y se devuelve su número de teléfono.
- Ignora mayúsculas y minúsculas al buscar.

### Modificar contacto

- Se introduce un nombre y un nuevo número para actualizarlo.

### Eliminar contacto

- Se introduce un nombre y se elimina del array.

### Listar todos los contactos

- Muestra todos los contactos almacenados.
