# Práctica de Métodos de Instancia: Estadísticas Avanzadas

## Objetivo

Crear un programa en Java que calcule estadísticas avanzadas de tres números utilizando métodos `public` (de instancia). El enfoque está en el uso de métodos de instancia, operaciones aritméticas y funciones matemáticas (como `Math.sqrt`), sin elementos avanzados de POO.

## Requisitos

- **Clase de Datos**: Crea una clase llamada `DatosEstadisticasAvanzadas` que contenga variables para almacenar tres números (tipo `double`): numero1, numero2, numero3.
- **Clase de Estadísticas**: Crea una clase llamada `EstadisticasAvanzadas` con métodos `public` para:
  - Calcular mediana: Recibe tres números, devuelve el valor medio ordenado (tipo `double`).
  - Calcular moda: Recibe tres números, devuelve el número que más se repite (si hay empate, el primero) (tipo `double`).
  - Calcular desviación estándar: Recibe tres números, devuelve la raíz cuadrada de la varianza (tipo `double`).
- **Clase Principal**: Crea una clase llamada `ProgramaPrincipal9` con el método `main` que:
  - Cree una instancia de `DatosEstadisticasAvanzadas` y asigne valores de ejemplo (por ejemplo, 10.0, 20.0, 10.0).
  - Cree una instancia de `EstadisticasAvanzadas` y llame a sus métodos para calcular.
  - Imprima los resultados en consola (estadísticas calculadas).

## Instrucciones Adicionales

- Todos los métodos deben ser `public`.
- Usa tipos primitivos `double`.
- Mantén la lógica simple: operaciones aritméticas básicas.
- El programa debe compilar y ejecutarse sin errores.
- Escribe el código de manera clara y comentada para un examen a mano.

## Ejemplo de Salida Esperada

```
Mediana: 10.0
Moda: 10.0
Desviación estándar: 4.08248290463863
```
