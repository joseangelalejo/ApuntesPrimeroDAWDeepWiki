# Pruebas Unitarias. Actividad de clase evaluable

- Crea un método llamado resta que tome dos números como parámetros y devuelva la resta de esos números.
- Escribe pruebas unitarias utilizando aserciones para verificar si el método Suma y Resta devuelve el resultado esperado para diferentes pares de números.
- Crea un método que le pase dos números, y que devuelva true si son iguales y false si no lo son
- Escribe un método de prueba unitaria que verifique si dos valores son iguales.
- Añade también los métodos Multiplicar y Dividir y realiza un método de prueba unitaria para cada caso de uso. Haz uso de los diferentes métodos existentes en Assert.
