# Actividad 27: CONFIGURACIÓN DE UN SERVIDOR PROXY CON SQUID Y CREACIÓN DE REGLAS DE FILTRADO

Instalar y configurar un servidor proxy utilizando Squid en un equipo Linux, dejándolo operativo para que los clientes de la red puedan navegar a través de él.

- Configurar el proxy para permitir el acceso a Internet a toda la red local 192.168.1.0/24.
- Comprobar desde un equipo cliente Windows que la navegación funciona correctamente al configurar manualmente el proxy.
- Crear una regla para bloquear el acceso a Internet a una dirección IP concreta de la red local.
- Crear una regla para bloquear el acceso a una página web concreta, por ejemplo [www.facebook.com](https://www.facebook.com).
- Crear una regla para bloquear el acceso a una segunda página web concreta, por ejemplo [www.instagram.com](https://www.instagram.com).
- Crear una regla para bloquear el acceso a varias páginas web relacionadas con ocio o redes sociales mediante una misma política de filtrado. (Investiga)
- Crear una regla para permitir el acceso a una página web determinada mientras el resto de páginas bloqueadas siguen restringidas.
- Configurar una regla de restricción horaria para impedir el acceso a determinadas páginas web dentro de una franja concreta del día.
- Configurar una regla de restricción horaria diferente para permitir la navegación solo en un intervalo horario específico.
- Crear una regla para impedir la descarga de archivos ejecutables desde los equipos cliente. (Investiga)
- Configurar una regla para bloquear palabras clave concretas dentro de las direcciones URL.  (Investiga)
