# Premisa Actividad 13 - Estructuras de control en Shell Scripts Debian | Opcional para practicar

Realiza un script en bash utilizando las estructuras de control aprendidas en la teoría (if, while, for, case). Cada script debe ajustarse a las premisas/enunciados que se indican a continuación:

1. Crear un menú con 3 opciones (a,b,c), al pulsar la opción que se muestre en consola, mostrar un mensaje indicando la opción seleccionada. Utilizar la estructura de control case para implementar el menú.
   1. Si se pulsa una opción incorrecta, que me muestre un mensaje de error y me solicite introducir una opción válida (while).
2. Pedir al usuario cuántos archivos.txt crear, solicitar una ruta que sea válida, si no es válida, solicitar la ruta de nuevo, los archivos se tienen que llamar arch1.txt, arch2.txt, arch3.txt, etc. (for).
