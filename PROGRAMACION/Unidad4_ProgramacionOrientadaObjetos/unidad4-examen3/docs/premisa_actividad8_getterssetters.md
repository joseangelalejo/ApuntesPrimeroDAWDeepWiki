# Premisa Actividad 8: Getters y Setters

CLASE 1=> Persona
Atributos:

- nombre
- edad

Constructor

- Un constructor que reciba el nombre y la edad y los guarde en los atributos.

Métodos

- Un método llamado mostrarDatos() que muestre por pantalla el nombre y la edad.

Getter y Setter

- Getter y setter de todos los atributos.

Programa principal

- Crear un objeto Persona.
- Mostrar sus datos.
- Cambiar la edad usando el setter.
- Volver a mostrar los datos.

CLASE 2=> Coche
Atributos:

- marca
- modelo
- velocidad

Constructor:

- Constructor que reciba marca y modelo.
- La velocidad inicial será 0.

Métodos:

- Método acelerar(int cantidad) que aumente la velocidad.
- Método frenar(int cantidad) que reduzca la velocidad.

Getter y Setter:

- Getter y setter de todos los atributos.

Programa principal

- Crear un coche.
- Acelerar el coche.
- Mostrar la velocidad usando el getter.

CLASE 3=> Libro
Atributos:

- titulo
- autor
- paginas

Constructor:

- Constructor con todos los atributos.

Métodos:

- Método esLargo() que devuelva true si el libro tiene más de 300 páginas y false en caso contrario.

Getter y Setter:

- Getter y setter de todos los atributos.

Programa principal

- Crear un libro.
- Mostrar el título.
- Indicar si es un libro largo.

CLASE 4=> Alumno
Atributos:

- nombre
- nota [], 10 notas

Constructor:

- Constructor con nombre y nota.

Métodos:

- Método aprobado() que devuelva true si la nota media es mayor o igual a 5.

Getter y Setter:

- Getter y setter de todos los atributos.

Programa principal:

- Crear un alumno.
- Mostrar su nombre.
- Indicar si está aprobado.
