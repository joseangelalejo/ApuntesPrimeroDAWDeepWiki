# Actividad 28:  Automatización con el programador de tareas

Tareas a realizar:

1. Crear un script que cambie el fondo de escritorio automáticamente al iniciar sesión, utilizando una imagen concreta guardada en el equipo.
2. Crear un script que muestre un mensaje personalizado de bienvenida al iniciar sesión del usuario.
3. Crear un script que genere automáticamente una carpeta con la fecha actual en el escritorio al iniciar sesión.
4. Crear un script que registre en un archivo de texto la fecha, la hora y el usuario de inicio, cada vez que se inicie sesión
5. Crear un script que haga una copia de seguridad de una carpeta a otra llamada Recovery cada 2 horas.
