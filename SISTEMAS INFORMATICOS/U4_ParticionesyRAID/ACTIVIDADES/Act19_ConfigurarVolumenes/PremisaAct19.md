# Premisa Actividad 19 - Configurar Volúmenes en Windows 10

En la máquina virtual de Windows Server o Windows 10, realiza las siguientes configuraciones de
almacenamiento:

1. Añade cuatro nuevos discos duros a la máquina virtual. Crea particiones para configurar los siguientes volúmenes.
2. Configura los siguientes volúmenes:
   - Crea un volumen distribuido.
   - Crea un volumen Seccionado.
   - Crea un volumen reflejado.
   - Crea un Raid 5 (Sólo en windows Server)
