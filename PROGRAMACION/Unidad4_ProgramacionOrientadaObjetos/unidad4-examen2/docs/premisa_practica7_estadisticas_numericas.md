# Práctica de Métodos de Instancia: Estadísticas Numéricas

## Objetivo

Crear un programa en Java que calcule estadísticas básicas de tres números utilizando métodos `public` (de instancia). El enfoque está en el uso de métodos de instancia, operaciones aritméticas y funciones matemáticas (como `Math.max`, `Math.min`), sin elementos avanzados de POO.

## Requisitos

- **Clase de Datos**: Crea una clase llamada `DatosNumeros` que contenga variables para almacenar tres números (tipo `double`): numero1, numero2, numero3.
- **Clase de Estadísticas**: Crea una clase llamada `EstadisticasNumeros` con métodos `public` para:
  - Calcular promedio: Recibe tres números, devuelve (n1 + n2 + n3) / 3 (tipo `double`).
  - Encontrar máximo: Recibe tres números, devuelve el mayor (tipo `double`).
  - Encontrar mínimo: Recibe tres números, devuelve el menor (tipo `double`).
  - Calcular suma: Recibe tres números, devuelve n1 + n2 + n3 (tipo `double`).
- **Clase Principal**: Crea una clase llamada `ProgramaPrincipal7` con el método `main` que:
  - Cree una instancia de `DatosNumeros` y asigne valores de ejemplo (por ejemplo, 10.0, 20.0, 15.0).
  - Cree una instancia de `EstadisticasNumeros` y llame a sus métodos para calcular.
  - Imprima los resultados en consola (estadísticas calculadas).

## Instrucciones Adicionales

- Todos los métodos deben ser `public`.
- Usa tipos primitivos `double`.
- Mantén la lógica simple: operaciones aritméticas básicas.
- El programa debe compilar y ejecutarse sin errores.
- Escribe el código de manera clara y comentada para un examen a mano.

## Ejemplo de Salida Esperada

```
Promedio: 15.0
Máximo: 20.0
Mínimo: 10.0
Suma: 45.0
```
