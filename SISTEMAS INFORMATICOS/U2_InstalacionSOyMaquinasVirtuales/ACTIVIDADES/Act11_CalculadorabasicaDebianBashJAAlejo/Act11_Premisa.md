# Calculadora básica en Bash

Crea un script en bash que funcione como una calculadora básica. El Script debe tener la siguiente funcionalidad:

1. Mostrar un menú con las siguientes opciones:
   - Sumar
   - Restar
   - Multiplicar
   - Dividir

2. Solicitar al usuario que elija una operación del menú.

3. Pedir al usuario que ingrese dos números.

4. Realizar la operación seleccionada con los números proporcionados.

5. Mostrar el resultado de la operación con un ECHO.

6. Además, los resultados de cada operación deben guardarse en un archivo de texto llamado "resultados.txt", con el formato: "Operación: [operación], Números: [número1], [número2], Resultado: [resultado]".
