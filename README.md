# Apuntes Primero DAW

Repositorio de apuntes, actividades, ejercicios y proyectos de **1º de Desarrollo de Aplicaciones Web**.

Esta copia está preparada como repositorio público de consulta. El material académico se conserva por módulos y unidades, mientras que los índices y README ayudan a localizarlo.

> **Nota:** Los apuntes y actividades son material educativo personal. En las entregas hay que respetar las indicaciones del profesor y revisar siempre el contenido antes de reutilizarlo.

Cada módulo incluye actividades, apuntes, ejercicios y recursos en su estructura original. Cuando un módulo tenga un README propio se utilizará como índice de estudio.

---

## Qué contiene

- Apuntes teóricos en Markdown y PDF.
- Actividades de clase y evaluables.
- Ejercicios de SQL, Java, HTML, CSS, XML, JSON, scripts y sistemas.
- Simulacros y repasos de examen.
- Proyectos académicos y personales.
- Guías de Git, VS Code y otras herramientas.
- Recursos gráficos y archivos auxiliares de las actividades.

---

## Cómo usarlo

1. Seleccionar el módulo.
2. Entrar en la unidad correspondiente.
3. Leer primero los apuntes o el documento `README.md` disponible.
4. Consultar la premisa de la actividad.
5. Revisar la solución, entrega o corrección cuando exista.
6. Ejecutar los ejercicios en un entorno apropiado.
