# Clase File

Escribe un programa en Java que realice las siguientes operaciones sobre un directorio especificado por el usuario:

- Verifique si es directorio y si tenemos permiso de escritura.
- Liste todos los archivos y directorios dentro del directorio especificado.
- Cree un nuevo directorio dentro del directorio especificado con el nombre dado por el usuario.
- Elimine todos los archivos con extensión ".txt" que sean mayores de 200B dentro del directorio especificado.
- Cuente y muestre la cantidad total de archivos y directorios dentro del directorio especificado.
- Borrar la carpeta de manera recursiva

El programa deberá solicitar al usuario que ingrese la ruta del directorio a operar y luego realizar las operaciones mencionadas. Asegúrate de manejar adecuadamente las posibles excepciones que puedan ocurrir durante estas operaciones.
