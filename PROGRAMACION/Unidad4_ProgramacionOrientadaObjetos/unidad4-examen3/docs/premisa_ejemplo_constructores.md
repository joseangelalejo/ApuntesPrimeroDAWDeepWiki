# Ejemplo de Constructores 1

Este módulo demuestra el uso de constructores en Java, incluyendo sobrecarga de constructores.

## Clases

- **Persona**: Clase con constructores sobrecargados (por defecto, con nombre, con nombre y edad, completo).
- **ProgramaPrincipal**: Clase principal que instancia objetos Persona usando diferentes constructores y muestra su información.

## Ejecución

Ejecuta `ProgramaPrincipal` para ver ejemplos de creación de objetos con diferentes constructores.
