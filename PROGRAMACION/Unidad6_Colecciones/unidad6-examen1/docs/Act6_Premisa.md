# Colas 3: Tarea

Escribe un programa en Java que simule un sistema de procesamiento de tareas. El programa debe tener dos clases principales: Tarea y ProcesadorTareas.

La clase Tarea debe tener un atributo id que represente el identificador único de la tarea + titulo y descripcion.

La clase ProcesadorTareas debe tener dos colecciones: una para las tareas pendientes y otra para las tareas completadas. Debe tener métodos para agregar tareas a la cola de pendientes (agregarTarea()), procesar las tareas pendientes (procesarTareas()), imprimir por pantalla la cola de tareas pendientes (imprimirColaPendientes()) y la colección de tareas completadas (imprimirColaCompletadas()).

Realiza un main para probar esto.

PLUS Meter prioridad en las tareas y tratar como una cola de prioridad.
