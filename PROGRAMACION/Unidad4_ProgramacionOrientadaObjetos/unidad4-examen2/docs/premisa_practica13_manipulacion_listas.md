# Práctica de Métodos de Instancia: Manipulación de Listas

## Objetivo

Crear un programa en Java que manipule listas simples (arrays) utilizando métodos `public` (de instancia). El enfoque está en el uso de métodos de instancia, bucles `for` y operaciones básicas con arrays, sin elementos avanzados de POO.

## Requisitos

- **Clase de Datos**: Crea una clase llamada `DatosLista` que contenga una variable para almacenar array (tipo `double[]`): lista.
- **Clase de Manipulación**: Crea una clase llamada `ManipulacionLista` con métodos `public` para:
  - Calcular suma: Recibe array, devuelve suma de elementos (tipo `double`).
  - Encontrar máximo: Recibe array, devuelve el mayor elemento (tipo `double`).
  - Contar positivos: Recibe array, devuelve cantidad de números > 0 (tipo `int`).
- **Clase Principal**: Crea una clase llamada `ProgramaPrincipal13` con el método `main` que:
  - Cree una instancia de `DatosLista` y asigne un array de ejemplo (por ejemplo, {1.0, -2.0, 3.0, 4.0}).
  - Cree una instancia de `ManipulacionLista` y llame a sus métodos para manipular.
  - Imprima los resultados en consola (manipulaciones realizadas).

## Instrucciones Adicionales

- Todos los métodos deben ser `public`.
- Usa tipos primitivos `double[]` e `int`.
- Mantén la lógica simple: bucles básicos.
- El programa debe compilar y ejecutarse sin errores.
- Escribe el código de manera clara y comentada para un examen a mano.

## Ejemplo de Salida Esperada

```
Suma: 6.0
Máximo: 4.0
Positivos: 3
```
