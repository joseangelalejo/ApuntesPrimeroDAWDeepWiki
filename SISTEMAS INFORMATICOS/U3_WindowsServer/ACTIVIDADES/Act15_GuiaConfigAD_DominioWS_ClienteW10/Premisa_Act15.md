# Premisa de Actividad 15(13) de Sistemas informáticos

Título Actividad: Configuración de Active Directory y Dominio en Windows Server, y Cliente en Windows 10

- **Parte 1**: Configuración del Controlador de Dominio en Windows Server
  - Instalar el Rol de Active Directory
  - Configurar el Servidor como Controlador de Dominio
  - Crear un  usuario en Active Directory
  - Crear usuario y configurar la zona horaria para poder iniciar sesión.
- **Parte 2**: Configuración del Cliente Windows 10 pro
  - Unir el Cliente al Dominio
  - Iniciar Sesión con una Cuenta de Dominio.
  - Inicia sesión con usuario fuera del rango horario y verifica que no pueda, luego cambia el rango horario e inicia de nuevo para que pueda entrar.
- **Modo de entrega**:
  - Un tutorial detallado en formato documento que contenga
  - Descripción breve de cada paso.
  - Capturas de pantalla claras para cada acción realizada
