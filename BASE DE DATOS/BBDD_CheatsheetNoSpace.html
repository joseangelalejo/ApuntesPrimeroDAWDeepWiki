Restricciones
PRIMARY KEY→Único + NOT NULL. Solo 1/tabla. Crea índice auto
UNIQUE→Valores únicos. Permite múltiples NULL. Crea índice
NOT NULL→Prohibe nulos. Solo nivel columna
FOREIGN KEY→Solo nivel tabla. Integridad referencial
CHECK→Limita rango. No puede referenciar otras tablas
DEFAULT→Valor automático si no se especifica
AUTO_INCREMENT→Solo con PK. NO con FLOAT
⚠ NULL = NULL → siempre UNKNOWN. Usar IS NULL / IS NOT NULL
Integridad referencial (FK)
CASCADE→Elimina/actualiza dependientes automáticamente
SET NULL→FK pasa a NULL al eliminar padre
RESTRICT→Prohíbe la operación (comportamiento por defecto)
ALTER — MODIFY vs CHANGE
MODIFY→Cambia tipo/restricciones. No renombra. Más seguro
CHANGE→Renombra + cambia tipo. Puede romper FK
Tipos de datos clave
INT→IDs, contadores. BIGINT si INT no alcanza
DECIMAL(m,d)→Dinero/precios. Precisión exacta. NUNCA FLOAT
VARCHAR(n)→Texto variable. Más común
CHAR(n)→Longitud fija (rellena con espacios)
BOOLEAN→= TINYINT(1). 0=false, 1=true
DATE→YYYY-MM-DD
DATETIME→Fecha+hora sin conversión automática
TIMESTAMP→Fecha+hora con actualización automática
ENUM('a','b')→Un solo valor de lista predefinida
SET('a','b')→Varios valores de lista predefinida
UNSIGNED→Solo positivos. Amplía rango positivo
ZEROFILL→Solo visual, no afecta al valor almacenado
Índices vs Vistas
Índice→Estructura física en disco. Optimiza búsquedas. Ocupa memoria
Vista→Tabla virtual. No almacena datos. Simplifica acceso y seguridad
PK y UNIQUE crean índices únicos automáticamente
DCL — Conceptos
user@localhost≠user@'%' → usuarios distintos en MySQL
Rol→Contenedor de privilegios. Por defecto desactivado al asignar
SET DEFAULT ROLE→Activa rol automáticamente al conectar
Niveles→Global → Base de datos → Tabla → Columna
U3 DDL / DCL — Sintaxis
Base de datos & tabla
CREATE DATABASE nombre;
USE nombre;
DROP DATABASE IF EXISTS nombre;

CREATE TABLE tabla (
  id   INT PRIMARY KEY AUTO_INCREMENT,
  col  VARCHAR(100) NOT NULL,
  sal  DECIMAL(8,2) CHECK(sal > 0) DEFAULT 0.00,
  tipo ENUM('A','B') DEFAULT 'A',
  ts   TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY(col_fk) REFERENCES otra(id)
    ON DELETE CASCADE
);
DROP TABLE IF EXISTS tabla;
Orden: DROP IF EXISTS → CREATE → tablas sin FK primero

             REFERENCES dep(id)

ALTER TABLE
ALTER TABLE t ADD col INT NOT NULL;
ALTER TABLE t DROP COLUMN col;

-- Solo tipo/restricciones (no renombra)
ALTER TABLE t MODIFY col VARCHAR(200) NOT NULL;

-- Renombra + cambia tipo

-- Restricciones
ALTER TABLE t ADD CONSTRAINT fk_x
  FOREIGN KEY(col) REFERENCES r(id);
ALTER TABLE t DROP CONSTRAINT fk_x;
DCL — Usuarios, Roles y Permisos
CREATE USER 'u'@'localhost' IDENTIFIED BY 'pwd';
CREATE USER 'u'@'%' IDENTIFIED BY 'pwd'; -- remoto
DROP USER   'u'@'localhost';

CREATE ROLE nombre_rol;
DROP ROLE   nombre_rol;

GRANT SELECT, INSERT ON db.* TO 'u'@'host';
GRANT ALL PRIVILEGES ON *.* TO 'admin'@'localhost';
GRANT rol TO 'u'@'host';
SET DEFAULT ROLE rol FOR 'u'@'host';

REVOKE INSERT ON db.tabla FROM 'u'@'host';
REVOKE rol FROM 'u'@'host';

Operadores WHERE
= <> > < >= <=→Comparación básica
BETWEEN a AND b→Rango (ambos incluidos)
IN (a,b,c)→Pertenencia a lista
LIKE '%x%'→% = 0..N chars   _ = exactamente 1 char
IS NULL→Nunca col = NULL (devuelve UNKNOWN)
AND / OR / NOT→AND tiene mayor precedencia que OR
LIKE vs IN→LIKE: patrones texto · IN: pertenencia a lista
Funciones de agregación
COUNT(*)→Todas las filas (incluye NULL)
COUNT(col)→Solo valores no-NULL
COUNT(DISTINCT c)→Valores únicos no-NULL
SUM / AVG→Ignoran NULL. Solo numéricos
MIN / MAX→Cualquier tipo comparable (texto, fecha, nº)
GROUP BY obligatorio al mezclar columnas normales con agregados
WHERE→Filtra filas antes de agrupar
HAVING→Filtra grupos después de GROUP BY
JOINs
INNER JOIN→Solo filas con coincidencia en ambas tablas
LEFT JOIN→Todas de izquierda + coincidentes de derecha (NULL si no hay match)
RIGHT JOIN→Todas de derecha + coincidentes de izquierda
CROSS JOIN→Producto cartesiano: cada fila × cada fila
NATURAL JOIN→Auto por nombre de columna. Peligroso si se añaden cols
USING(col)→Las cols a unir deben tener el mismo nombre
Alias obligatorio→Si la tabla aparece más de una vez (self-join) o hay ambigüedad
Subconsultas
En WHERE→Escalar (1 valor) o con IN / NOT IN / ALL / ANY
En SELECT→Debe devolver 1 solo dato por fila
EXISTS→Comprueba si hay filas. SELECT 1 porque solo importa existencia
Correlacionada→Referencia columnas externas. Ejecuta 1 vez por fila
UNION
UNION→Elimina duplicados (más lento)
UNION ALL→Conserva duplicados (más rápido)
Ambas consultas: mismo número y tipo de columnas
INSERT / UPDATE / DELETE
DELETE→Fila a fila, admite WHERE, rollback posible
TRUNCATE→Más rápido, generalmente sin rollback, sin WHERE
DROP→Elimina estructura + datos completos
⚠ UPDATE y DELETE sin WHERE → afectan TODAS las filas
U4 DML — Sintaxis
SELECT básico
SELECT col1, col2 AS alias FROM tabla;
SELECT DISTINCT col FROM tabla;
SELECT CONCAT(col1,' ',col2) AS nombre FROM t;
SELECT * FROM t WHERE col > 10
  AND col2 LIKE 'A%';
SELECT * FROM t WHERE col BETWEEN 10 AND 20;
SELECT * FROM t WHERE col IN (1,2,3);
SELECT * FROM t WHERE col IS NULL;
ORDER BY col DESC, col2 ASC;
LIMIT 10;   LIMIT 10 OFFSET 5;
Agregación + GROUP BY + HAVING
SELECT col,
  COUNT(*), SUM(x), AVG(x),
  MIN(x), MAX(x)
FROM tabla
WHERE condicion_filas      -- filtra ANTES
GROUP BY col
HAVING COUNT(*) > 5;       -- filtra DESPUÉS
INSERT / UPDATE / DELETE
INSERT INTO t (c1,c2) VALUES (v1,v2),(v3,v4);
INSERT INTO t SELECT * FROM t2 WHERE ...;

UPDATE t SET c=v, c2=c2+1 WHERE id=1;
UPDATE a INNER JOIN b ON a.id=b.id
  SET a.col = b.col;

DELETE FROM t WHERE id = 1;
TRUNCATE TABLE t; -- sin WHERE, sin rollback
CASE WHEN
SELECT col,
  CASE
    WHEN col > 100 THEN 'Alto'
    WHEN col > 50  THEN 'Medio'
    ELSE 'Bajo'
  END AS categoria
FROM tabla;
JOINs
SELECT a.col, b.col
FROM tablaA a
INNER JOIN tablaB b ON a.id = b.id_a;

LEFT JOIN  tablaB b ON a.id = b.id_a;
RIGHT JOIN tablaB b ON a.id = b.id_a;
CROSS JOIN tablaB;

-- USING (cols con mismo nombre)
INNER JOIN tablaB USING(id_comun)

-- Múltiples JOINs
FROM a
  INNER JOIN b ON a.x = b.x
  INNER JOIN c ON b.y = c.y
Subconsultas
-- Escalar en WHERE
SELECT * FROM t
WHERE col > (SELECT AVG(col) FROM t);

-- IN
SELECT * FROM t WHERE id IN
  (SELECT id FROM t2 WHERE ...);

-- EXISTS
SELECT * FROM a WHERE EXISTS
  (SELECT 1 FROM b WHERE b.id = a.id);

-- En SELECT (1 valor por fila)
SELECT col,
  (SELECT COUNT(*) FROM b
   WHERE b.id = a.id) AS cnt
FROM a;
UNION + Fechas
SELECT col FROM tablaA
UNION      -- sin duplicados
SELECT col FROM tablaB;
UNION ALL  -- con duplicados (más rápido)
