# Práctica de Métodos de Instancia: Procesamiento de Fechas

## Objetivo

Crear un programa en Java que procese fechas simples utilizando métodos `public` (de instancia). El enfoque está en el uso de métodos de instancia, condicionales y operaciones básicas con enteros, sin elementos avanzados de POO.

## Requisitos

- **Clase de Datos**: Crea una clase llamada `DatosFecha` que contenga variables para almacenar fecha (tipo `int`): dia, mes, anio.
- **Clase de Procesamiento**: Crea una clase llamada `ProcesamientoFecha` con métodos `public` para:
  - Obtener días en mes: Recibe mes y anio, devuelve días en ese mes (tipo `int`).
  - Verificar si es bisiesto: Recibe anio, devuelve true si es bisiesto (tipo `boolean`).
  - Validar fecha: Recibe dia, mes, anio, devuelve true si la fecha es válida (tipo `boolean`).
- **Clase Principal**: Crea una clase llamada `ProgramaPrincipal11` con el método `main` que:
  - Cree una instancia de `DatosFecha` y asigne valores de ejemplo (por ejemplo, 29, 2, 2024).
  - Cree una instancia de `ProcesamientoFecha` y llame a sus métodos para procesar.
  - Imprima los resultados en consola (procesamientos realizados).

## Instrucciones Adicionales

- Todos los métodos deben ser `public`.
- Usa tipos primitivos `int` y `boolean`.
- Mantén la lógica simple: condicionales básicos.
- El programa debe compilar y ejecutarse sin errores.
- Escribe el código de manera clara y comentada para un examen a mano.

## Ejemplo de Salida Esperada

```
Días en mes: 29
Es bisiesto: true
Fecha válida: true
```
